আবেদনকারীর প্রোফাইল

সকল আবেদনকারীর প্রোফাইল পরিচালনা করুন।

আবেদনকারী মোবাইল ইমেইল প্রোফাইল তারিখ অ্যাকশন

আবেদনসমূহ

চাকরির সকল আবেদন এবং স্ট্যাটাস পরিচালনা করুন।

আবেদনকারী আবেদন ID চাকরি পেমেন্ট স্ট্যাটাস তারিখ অ্যাকশন

পেমেন্ট

আবেদন ফি এবং পেমেন্ট যাচাই করুন।

আবেদন ID পদ্ধতি পরিমাণ প্রেরকের নম্বর TrxID তারিখ স্ট্যাটাস অ্যাকশন

সিভি ব্যবস্থাপনা

আবেদনকারীর আপলোড করা CV এবং প্রশাসনিক CV ব্যবস্থাপনা করুন।

সিভি ব্যবস্থাপনা এখান থেকে করা যাবে।

আবেদনকারীর প্রোফাইল বা আবেদন থেকে CV দেখুন, ডাউনলোড বা প্রিন্ট করুন।
